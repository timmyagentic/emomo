NEXT / 接入 CLI

最后一步，交给你的 Agent。

安装 Emomo CLI，下载上方密钥文件，然后在 macOS / Linux 执行：

chmod 600 ~/Downloads/emomo-access.key
emomo auth configure --key-file ~/Downloads/emomo-access.key
emomo doctor --api-url https://api.timmyagentic.si/agent/v1

Windows 请将文件路径替换为实际下载路径，无需 chmod。密钥配置不会改变已有本地图库。
