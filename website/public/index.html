继续用熟悉的对话方式。Emomo 负责检索和完整图片，Agent 负责理解与选择。

01

先懂这句怎么回

开心、无奈，还是礼貌地阴阳怪气？把语境变成简短关键词。

“表达收到，但有点不情愿。”

02

找到候选，再看一眼

从文字和审核标签中检索，再查看真实画面，确认内容与语气。

emomo search "收到" --limit 5
03

把原图带回对话

下载完整图片，不裁切、不重绘。尺寸、格式和校验值随结果返回。

emomo download <id> --dir ./memes

SMALL TOOL. CLEAR BOUNDARIES.

小工具，也有自己的坚持。

让 Agent 理解，让检索找图

共享搜索使用确定性文字检索，不调用大模型，也不需要你的模型密钥。语气与画面的判断，留给你正在使用的 Agent。

自己的收藏，留在本地

共享静态图库之外，CLI 也支持离线本地图库。保留完整图片和动画，本地模式不上传你的收藏。

拿到原图，再自由使用

图片不裁切、不重绘，完整字节与校验值一起返回。代码采用 MIT 许可，图片权利仍属于各自权利人。

接入已有的工作流

使用随包 Skill、直接调用 CLI，或接入 REST API。统一 JSON 输出与明确错误码，让每一步都能接得上。

GOOD QUESTIONS

你可能还想知道

这是一个聊天应用吗？

Emomo 提供表情包检索工具。你继续使用现有的 Agent，由它搜索、看图和选择。此官网提供项目介绍、安装与接口文档。

需要付费或提供模型密钥吗？

共享检索需要 Emomo 访问密钥，登录官网后即可自助创建；搜索、详情和下载分别计量，同一账户的密钥共享账户额度，具体额度可在账户页查看。同一 IP 和同一密钥的搜索与下载均需间隔 1 秒，超限按返回时间退避。Emomo 搜索服务不调用模型；使用者的 Agent 仍可能消耗自己的模型额度。

支持 GIF 和动态表情吗？

首个公开图库提供 PNG、JPEG 和静态 WebP。本地图库支持完整 GIF 等动画，前提是你拥有相应原件；静态首帧不会被当作完整动画。

图片可以商用吗？

代码采用 MIT 许可，图库图片不适用代码许可证。图片权利属于各自权利人，我们不提供商用授权承诺。请按你的使用场景确认权限；权利人可通过 GitHub Issue 提供图片 ID 申请处理。

没有搜到合适的怎么办？

让 Agent 换一个更直接的关键词，或用画面中的文字搜索。没有结果是有效结果；不要把不相关的图当作已满足请求。远程检索是关键词匹配，不保证理解所有语义。
