03 / SMALL TOOL, CLEAR BOUNDARIES

简单的工具，清楚的分工。

Agent 负责理解，检索负责找图

共享服务使用确定性文字检索，不调用大模型。你的 Agent 用自己的会话理解语境和查看候选，无需向 Emomo 提供模型凭据。

公开图库，也支持自己的收藏

开箱即可搜索公开静态图库。CLI 同时支持离线本地图库，保留完整图片与动画；本地模式不上传你的收藏。

保留图片，保留判断

完整原图不裁切、不重绘。相似版本已折叠，模糊文字不参与索引；搜索分数表示词汇相关度，语气仍由 Agent 判断。

接入方式，由你决定

使用随包 Skill，直接调用 CLI，或接入 REST API。统一 JSON 输出，明确错误码，适合已有的 Agent 工作流。

GOOD QUESTIONS

你可能还想知道

这是一个聊天应用吗？

Emomo 提供表情包检索工具。你继续使用现有的 Agent，由它搜索、看图和选择。此官网提供项目介绍、安装与接口文档。

需要付费或提供模型密钥吗？

当前公开检索无需账户或密钥，每个边缘节点按同一 IP 约每分钟 30 次请求限流，可能有短暂误差。Emomo 搜索服务不调用模型；使用者的 Agent 仍可能消耗自己的模型额度。

支持 GIF 和动态表情吗？

首个公开图库提供 PNG、JPEG 和静态 WebP。本地图库支持完整 GIF 等动画，前提是你拥有相应原件；静态首帧不会被当作完整动画。

图片可以商用吗？

代码采用 MIT 许可，图库图片不适用代码许可证。图片权利属于各自权利人，我们不提供商用授权承诺。请按你的使用场景确认权限；权利人可通过 GitHub Issue 提供图片 ID 申请处理。

没有搜到合适的怎么办？

让 Agent 换一个更直接的关键词，或用画面中的文字搜索。没有结果是有效结果；不要把不相关的图当作已满足请求。远程检索是关键词匹配，不保证理解所有语义。
